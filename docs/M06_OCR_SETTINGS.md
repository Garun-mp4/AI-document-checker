# M06 — настройки и повторный OCR

## Поведение по умолчанию

Обычная загрузка по-прежнему автоматически распознаёт подозрительно неполные страницы PDF на русском и английском (`rus+eng`) с настройкой 200 DPI. Открытие оригинала не запускает OCR. У каждого PDF-просмотрщика есть сводка и раскрываемые статусы всех страниц: текстовый слой, распознанный текст, пустая страница, отсутствие текста, ограничение числа страниц.

## Повторная обработка

Кнопка **Настроить OCR** позволяет выбрать язык, качество и область. Пресеты: 150 DPI (быстрее), 200 DPI (рекомендуемый баланс) и 300 DPI (медленнее, для мелкого текста). Режим «Все страницы, для которых нужен OCR» повторно запускает страницы, ранее классифицированные как скан/распознанные/непрочитанные. Режим выбранных страниц позволяет выбрать нужные страницы вручную, включая страницы с обычным текстовым слоем.

До запуска показывается подтверждение: обработка создаст новую версию текста, индекса и анализа. Оригинальный файл и история чата сохраняются. Пока новая версия не прошла обработку и анализ, активными остаются старые ответы и citations; старые citation ID разрешаются к их прежним chunks. Если попытка завершается ошибкой или отменяется, активная версия не публикуется.

Максимум страниц задаёт `OCR_MAX_PAGES` (по умолчанию 100, допустимо 1–500). Если PDF содержит больше подходящих страниц, нужно запускать выбранные группы по очереди. Предел символов задаётся `OCR_MAX_CHARS`, время — `OCR_TIMEOUT_SECONDS`.

## Порог качества

`OCR_CONFIDENCE_WARNING_THRESHOLD` задаёт порог 0–100, по умолчанию 60. Приложение предупреждает о страницах, у которых среднее значение confidence Tesseract ниже порога. Значение не оценивает вероятность правильности текста: это эвристический сигнал для ручной проверки оригинала. Предупреждение не скрывает оригинал и не блокирует работу с доступным текстом.

```dotenv
OCR_CONFIDENCE_WARNING_THRESHOLD=60
OCR_MAX_PAGES=100
```

Переопределение добавляется в `.env` перед запуском/пересборкой Compose. Английские и русские traineddata поставляются worker-образом; если установленный пакет недоступен, ошибка сообщает конкретный выбранный языковой режим и не заменяет активную версию.

## Проверки

- `backend/tests/test_ocr_settings.py` проверяет поддерживаемые варианты, ограничения страниц и диапазон порога.
- `backend/tests/test_ocr.py` проверяет выбранный язык/DPI, метаданные confidence и понятную ошибку для отсутствующего traineddata.
- `backend/tests/test_processing.py` проверяет перенос неизменённых OCR-страниц вместе с координатами и замену только выбранной страницы.
- `backend/tests/test_compose_workflow.py` проверяет endpoint, параметры очереди, неизменность активной версии и исходного файла при ошибке анализа.
- `frontend/e2e/ocr.spec.mjs` проверяет настройки, подтверждение, запрет параллельного повтора, отмену без потери активной версии, повторную обработку выбранных страниц, сохранение координат остальных страниц и доступность старых citations после reload. Текстовый PDF проверяется отдельно: автоматическая область OCR равна нулю, но ручной выбор страницы остаётся доступен.
