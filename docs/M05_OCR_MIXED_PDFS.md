# M05 — OCR смешанных PDF и карта координат

M05 добавляет постраничный OCR для PDF, в которых одновременно есть обычные текстовые страницы, сканы и пустые листы. Оригинальный PDF остаётся неизменным; новый результат анализа и карта источников сохраняются в текущей версии обработки документа.

## Выбор страниц и объединение текста

Native-парсер классифицирует каждую страницу отдельно: `native`, `ocr_candidate` или `blank`. Пустой лист определяется отсутствием содержимого страницы и не отправляется в OCR. Текстовый слой считается подозрительным, если он отсутствует, слишком короток или содержит признаки повреждённого извлечения. Для OCR отправляются только такие страницы.

Для страницы-кандидата используется текст Tesseract как единый источник: её возможный неполный native-слой не добавляется рядом и не создаёт дублей. Надёжные native-страницы сохраняются как есть. OCR выполняется по одной странице через Poppler с CropBox; после обработки растр освобождается. Сбой распознавания отдельной страницы сохраняется в карте как `unreadable`, не выбрасывает удачные результаты соседних страниц, а документ остаётся готовым, если в нём есть доступный текст. В API такой результат имеет `ocr_status=partial` и показывает номера непрочитанных страниц.

Markdown формируется в исходном порядке страниц, с заголовком `## Страница N`. Пустые страницы не добавляются. В нём остаётся только один выбранный текстовый источник на страницу, связанный с native locator либо OCR locator.

## Карта OCR и подсветка

OCR locator содержит страницу, диапазон символов и строк исходного OCR-текста, confidence, DPI, язык, версию Tesseract, CropBox, поворот и размеры raster. Координаты слов и строк записываются как целочисленные прямоугольники в системе `page-normalized-top-left` со шкалой `0..10000`; каждый прямоугольник дополнительно связан с диапазоном символов и номером строки.

PDF.js рисует подсветку на исходном canvas по этим нормализованным координатам. Viewer страницы учитывает тот же поворот, а Poppler rasterizes с CropBox, поэтому положение не зависит от ширины колонки и zoom. Клик на OCR-цитату открывает нужную страницу, прокручивает к области и выделяет все слова связанного фрагмента. Если legacy locator не содержит коробок, viewer открывает страницу и предлагает повторную обработку для создания карты.

## Обработка ошибок и ограничения

- Пустые страницы пропускаются без предупреждения о неудачном OCR.
- Неразборчивая или неотрендеренная отдельная страница помечается как частичная; читаемые страницы и их источники сохраняются.
- Если после native parsing и OCR нигде нет значимого текста, документ получает понятную ошибку вместо пустого индекса.
- Слишком большие, зашифрованные или повреждённые PDF остаются в рамках текущих ограничений и безопасного worker.
- OCR остаётся локальным; пользовательский выбор DPI/языка и ручной повтор с настройками относятся к M06.

## Проверки

Покрытие M05 включает реальные синтетические PDF с native-страницей, русско-английским сканом, пустой страницей, повёрнутой/обрезанной страницей; unit-тесты классификации, объединения источников, нормализации координат и таймаута страницы; backend Compose API тест с настоящими Poppler/Tesseract; браузерный тест перехода citation и отрисовки OCR word boxes.

Изолированный E2E Compose-проект использует собственные volumes. M05-проверки запускаются в нём без сброса существующих volumes; production volumes и Codex-авторизация для synthetic-тестов не используются.
